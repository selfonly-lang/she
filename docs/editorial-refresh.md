# SHE 雜誌介面更新

以米白、墨黑、酒紅、襯線標題與大幅封面，統一首頁、商品、女性人物、人物專頁、會員中心、編輯室、商品管理與條款頁。

## 共用介面

- `assets/editorial.css` 管理視覺與響應式排版；`assets/editorial.js` 增強手機選單、目前頁面指示、商品搜尋／分類、返回頂端與人物視窗焦點。
- 導覽、頁尾、各分頁標題與會員登入版型已放在 HTML，載入共用程式前即可呈現。手機選單支援 Escape，故事視窗支援鍵盤開啟、焦點循環與關閉後返回觸發位置。
- 動畫以簡短淡入、卡片與圖片互動為主；尊重 `prefers-reduced-motion`。使用一般 CSS 進場動畫，避免跨頁 View Transition 在部分情境拋出例外。
- 首頁保留示範人物標示；女性人物頁仍只顯示資料庫已發布內容。未發布／找不到的專頁有返回入口。

## 登入與權限

- 保留 Email／密碼兩欄、註冊同意與驗證信回站流程；不自動合併其他帳號。
- 從編輯室或商品管理頁進入登入，成功後可返回原頁。只允許 `/studio/` 與 `/manage-products/`，導向狀態在分頁內保存十分鐘；身分連結確認與新 LINE 會員檔案流程優先。
- 會員資料請求有十五秒逾時。商品、訂單等資料仍在背景載入；職務資料不可用時不授予後台職務，仍可進入已驗證的一般會員畫面。
- 商品管理入口按既有職務顯示；資料庫 RLS 仍是權限依據。修復批次管理既有 `throw out.errorawait load()` 語法錯誤，未改寫批次操作 RPC 或價目邏輯。
- LINE Login 與 SELF OAuth 是否啟用仍以 `/api/auth?action=status` 為準。此視覺更新不代表已完成正式身分供應商授權；設定方式見 `auth-setup.md`。

## 圖片與載入

首頁 32 個內嵌圖片引用改成 16 個去重的內容雜湊檔案，保留原始圖片位元組。首頁 HTML 從約 1.19 MB 降至約 83 KB；圖片另外載入，不代表整個頁面的總傳輸量只有 83 KB。

`vercel.json` 為雜湊封面圖片設定一年 immutable 快取。開發伺服器新增 JPG、PNG、WEBP MIME 類型。更新封面時使用新的內容雜湊檔名。

## 驗證

- `npm test`：20 個獨立 API 測試，含設定不足時停用社群登入、交易狀態、PKCE、同意、身分綁定與資料保護。
- 瀏覽器檢查涵蓋八頁的 1440px／390px 畫面、手機導覽、公開商品篩選、人物鍵盤視窗、匿名編輯預覽與送審限制、閱讀字級及減少動態偏好。
- 登入測試替身涵蓋 Email 驗證提示、慢速狀態請求、次要服務失敗、回站允許清單、角色讀取失敗、既有資格保留與登出。
- 測試替身不會建立正式會員、寫入正式資料或發送 LINE 訊息，亦不能取代真實 LINE 手機授權驗收。
